# Linked List Approaches
* CycleCheck - hash nodes of list
* CloneListWithNextAndRandomPointer - hash nodes of list with their deep copies
* IntersectionCheck -
    * compare every node of list 1 with every node of list 2
    * hash nodes of list 1, compare with nodes of list 2
    * find difference between length of lists, place first pointer at distance of
    difference from head of list 1, move pointers together
* MergeTwoSortedLists - place pointers at head of lists, put smaller node in new
list, move corresponding pointer
* MiddleNode, RemoveKthNodeFromLast - find length of list
* RotateList - pick last node, place it at front
