# Other Approaches
* MiddleNode - find length of list
* NthNodeFromLast - find length of list
* CycleCheck - hash nodes of list
* IntersectionCheck -
    * compare every node of list 1 with every node of list 2
    * hash nodes of list 1, compare with nodes of list 2
    * find difference between length of lists, place first pointer at distance
    of difference from head of list 1, move pointers together
* MergeTwoSortedLists - place pointers at head of lists, put smaller node in
new list, move corresponding pointer
* RotateList - pick last node, place it at front
