# Types of Binary Trees
* Full - 0 or 2 children only
* Complete - All levels are completely filled except last level and nodes of last level are as left as possible
* Perfect - All leaf nodes are on the same level
* Balanced - Max. height is log(total no. of nodes)
* Degenerate - Skewed

# Types of Traversal Algorithms
* Preorder - Root->Left->Right
* Inorder - Left->Root->Right
* Postorder - Left->Right->Root
* Level order - Nodes on same level first
