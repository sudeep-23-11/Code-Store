* ETL = Extract Transform Load

* Star schema
    * Fact table
        * single table
        * quantitative data
        * e.g. product ID
    * Dimension table
        * multiple tables
        * qualitative data
        * e.g. product details

* Snowflake schema
    * Sub-dimension table = e.g. location details
    * normalization

* OLTP database
    * Online Transaction Processing
    * current data
    * data generated from transactions
    * real time operations

* OLAP database
    * Online Analytical Processing
    * historical data
    * data used for analysis and decision making
    * periodically batch operations

* SQL database
    * data in row-column in table
    * fixed schema

* NoSQL database
    * data in document (key-value pairs) in collection
    * variable schema
