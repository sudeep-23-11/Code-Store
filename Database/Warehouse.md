* ETL = Extract Transform Load
* Star schema
    * Fact table = single table, quantitative data, e.g. product ID
    * Dimension table = multiple tables, qualitative data, e.g. product details
* Snowflake schema
    * Sub-dimension table = e.g. location details
    * Normalization
* OLTP database
    * Online Transaction Processing
    * Current data, data generated from transactions
    * Real time operations
* OLAP database
    * Online Analytical Processing
    * Historical data, data used for analysis and decision making
    * Periodically batch operations
* SQL database
    * data in row-column in table
    * fixed schema
* NoSQL database
    * data in document (key-value pairs) in collection
    * variable schema
