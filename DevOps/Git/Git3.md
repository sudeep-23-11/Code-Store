# Global
* git config --global user.name N -- name is N
* git config --global user.email E - email is E
* git config --list ---------------- details
* git config --global alias.X Y ---- X is alias of Y
* git init ------------------------- initialize repository as git
* git status ----------------------- status of repository


# LFS
* git lfs install ------------------ initialize repository as git lfs
* git lfs track *.E ---------------- track files having extension E as lfs


# Workspace
* .gitignore ----------------------- not track its content
* .gitattributes ------------------- track its content as lfs
* .git ----------------------------- metadata of repository
