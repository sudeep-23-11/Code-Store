* b main --------------------------- breakpoint at beginning of program
* b -------------------------------- breakpoint at current line
* b _ ------------------------------ breakpoint at line no. _
* b +_ ----------------------------- breakpoint at _ lines from current line
* b _ ------------------------------ breakpoint at beginning of function _
* d _ ------------------------------ delete breakpoint _
* info b --------------------------- list breakpoints
*
*
* r -------------------------------- run program until breakpoint
* c -------------------------------- continue running program until breakpoint
* f -------------------------------- execute current function
* s -------------------------------- execute next line
* s _ ------------------------------ execute next _ lines
* n -------------------------------- execute next line and do not step in function
* l -------------------------------- list lines
*
*
* p _ ------------------------------ print value of variable _
* q -------------------------------- exit
* help _ --------------------------- manual for command _
